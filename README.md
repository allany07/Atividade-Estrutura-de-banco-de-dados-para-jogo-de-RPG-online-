# Atividade-Estrutura-de-banco-de-dados-para-jogo-de-RPG-online-
Script SQL desenvolvido para a atividade de criação do banco de dados de um jogo de RPG online. O arquivo cria o banco RPGOnline e suas tabelas — usuários, personagens, classes, habilidades e a relação entre classes e habilidades — com chaves primárias e estrangeiras para representar os relacionamentos do diagrama ER.
